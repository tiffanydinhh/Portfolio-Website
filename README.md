# Portfolio Website
My personal portfolio website that showcases all of the projects I developed and the graphic designs I created.

# Purpose
This project was developed to give me a space to showcase my projects and strengthen my front-end development and UI/UX skills, as it allowed me to:
* Create a website from scratch
* Design in Figma and translate wireframes into a functional website
* Build upon my HTML and CSS knowledge

## Features
* **Home Page:** Cohesive styling and clickable buttons that jump to different sections of the page with hover animations.
* **Projects Section:** An organized section on the home page that displays each project and its description.
* **Designs Section:** An organized section on the home page that displays my graphic designs.
* **Contact:** Clickable link in the nav bar that allows users to reach me through email.
* **Github:** Clickable link in the nav bar that allows users to visit my GitHub.
